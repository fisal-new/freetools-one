Star history FAQ
How do I see a GitHub repo star history?
Type user/repo above and press ADD — for example torvalds/linux. The chart draws every week from the repo creation day to today.
Can I compare multiple repos?
Yes, add up to 6 GitHub or GitLab repos. Each gets its own color, totals and 30-day growth in the stats table.
Is there a star history API?
Yes: /v1/stars?github=user/repo returns JSON, and /v1/stars/chart?github=user/repo returns an SVG image you can embed in a README.

Chart how a GitHub or GitLab repository's stars grew over time, compare up to six repos, and export the result as SVG, PNG or CSV.

Frequently asked questions

How do I get a GitHub star history chart?

Enter user/repo in the box above, or call /v1/stars?github=user/repo for the raw data and /v1/stars/chart?github=user/repo for a ready-to-embed SVG image.

Can I compare two repositories at once?

Yes. Add up to six repositories, from GitHub and GitLab mixed, and each gets its own colour, total and 30-day growth figure.

How can I put the chart in my README?

Use the SVG endpoint as a Markdown image: ![Star History](https://freetools.one/v1/stars/chart?github=your/repo). It updates automatically as the repository grows.

Why are GitHub points weekly?

GitHub restricts its stargazer list and publishes a weekly history endpoint. FreeTools uses that official endpoint and anchors the series to the live star total, so the last point always matches the current star count.
