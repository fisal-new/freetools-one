Description
- API to generate random data
- Only supports GET request.
- Limit : 300 requests per minute. Once reached subsequent requests will result in error 429 (too many requests) until your quota is cleared.
Endpoint - Get Random Integers
HTTP Request:
GET /v1/random/integer?min=X&max=Y[×=N]
Examples
Get random number between 1-10 both inclusive
/v1/random/integer?min=1&max=10
Valid Range: 0 - 10,000,000,000
You can also specify how many times you want the result with the parameter times.
Default is 1 and there is no need to specify it. Max times = 10,000
/v1/random/integer?min=1&max=10×=50
response

How to use the Random Data API

  
Generate random integers, shuffled lists and names for testing, seeding and load generation.

  
Endpoints

  
EndpointReturnsExample

  
/v1/random/integerJSONmin=1&max=10

  
/v1/random/listJSONlen=10

  
/v1/random/nameJSON

  

  
Parameters

  
NameTypeDefaultDescription

  
minintegerrequiredLowest value for /v1/random/integer.

  
maxintegerrequiredHighest value for /v1/random/integer.

  
timesinteger1How many integers to generate, 1-10000.

  
lenintegerrequiredLength of the shuffled list for /v1/random/list, 2-10000.

  

  
Code examples

  

  
curl 'https://freetools.one/v1/random/integer?min=1&max=100&times=5'

  
const r = await (await fetch('https://freetools.one/v1/random/integer?min=1&max=6')).json();
console.log(r.data[0]); // dice roll

  
import requests

r = requests.get('https://freetools.one/v1/random/integer',
                 params={'min': 1, 'max': 6}).json()
print(r['data'][0])

Frequently asked questions

  

  
How do I simulate a dice roll in code?
Call /v1/random/integer?min=1&max=6 and read data[0]. That is exactly a standard six-sided die.

  
Is the random data API suitable for load testing?
Yes. /v1/random/* allows 300 requests per minute, and /v1/random/integer?times=10000 returns ten thousand values in a single call, which is far cheaper than looping.

  
What randomness source is used?
Values come from the operating system CSPRNG (/dev/urandom) on the server, not from a seeded PRNG, so results are not predictable.

  
Can I get random names?
Yes. /v1/random/name returns a random surname from a built-in list.
