Opens a small window. Press get code, open the link it copies, finish the offer, paste the key back, press activate. The Hub and the Spy load from there.

What you get

  • Hub — full menu UI, game detection across 30+ games, and a scripts panel that fetches 93 sources at click time.
  • Spy — property inspector and remote spy. It builds its own UI layer on start, so give it a moment after the executor reports it running.
  • A key lasts a day, works every time you use it, and goes to the first account that activates it. After that nobody else can use it.

Before you run it

  • These run in your executor, not in Roblox. Anyone who can run a script can also read it — that is true of every script, including paid ones.
  • Use an account you can afford to lose. Exploits get accounts flagged, and so do the scripts people load into them.
  • If a link 404s, the file moved. Check the repos rather than trusting a mirror.
